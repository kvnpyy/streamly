# Streamly — UI description for Samsung verification

Use this outline to build a **PPTX or PDF** (5–6 slides) and upload under **Verification Info → App description file**.

## Slide 1 — Overview

**Streamly — IPTV web player**

- Media player for the user’s own Xtream or M3U subscription
- Does not sell or host TV channels
- Optimized for Samsung TV remote (D-pad focus, PIN login)

---

## Slide 2 — Sign in (PIN)

Screenshot: `01-login.jpg`

1. User opens Streamly on Samsung TV
2. Default tab: **Link with PIN**
3. On phone/PC: Settings → **Link a TV with a PIN** → 6-digit code
4. Enter code on TV → connected
